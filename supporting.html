Eight-step troubleshooting method

Use the method as a loop: evidence can send you back to the problem statement or hypotheses. Preserve uncertainty and validate the original service after any mitigation.

Define the problem

State the affected user operation, scope, time and expected behavior. Distinguish impact from detection time.
