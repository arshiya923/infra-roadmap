Build a safe place to practice

Recommended Infrastructure Lab

Equivalent hardware and software are welcome. Physical hardware is not mandatory. Use legally obtained images and licenses, isolated networks and disposable test workloads.

01 / Beginner

Learn packet behavior

  • Cisco Packet Tracer
  • GNS3 or EVE-NG
  • Wireshark
  • Linux VM
  • Windows Server VM

Start with a small topology; capture traffic and keep a lab notebook.

02 / Intermediate

Operate an enterprise lab

  • Cisco IOSv / IOSvL2
  • CSR1000v / Catalyst 8000V
  • NX-OSv
  • FortiGate VM or equivalent firewall
  • Windows Server / Ubuntu Server
  • VMware ESXi or equivalent hypervisor

Check platform support and host resources before installing virtual appliances.

03 / Advanced physical

Test real dependencies

  • Catalyst 2960X / 9200
  • Cisco ISR4331
  • Nexus 3K / 5K / 9K
  • Access point + wireless controller
  • HPE DL380 Gen9 / Gen10
  • SAN storage + Brocade or Cisco SAN switch
  • UPS + managed PDU

Use equivalent platforms where practical; size power, memory and storage first.

Final project / design • validate • defend

Enterprise Data Center Architecture Capstone

Design an enterprise environment that can survive a failed link, device, power path or site. Explain every dependency, test your recovery assumptions, and make the design reproducible.
