A protocol candidate may remain as inactive information; absence of the kernel path is not proof that every topology/RIB object was deleted. Both endpoint exchanges fail while local client/server gateways work. This is an attachment interruption, not a passive-interface or AS-mismatch injection.

## Separate supplied-distance worksheet

The worksheet freezes one ordinary internal prefix, three established compatible neighbors, their supplied positive total/reported distances and a known completed historical FD. It applies strict `RD < FD` before selecting the least supplied total among locally feasible candidates. With FD 100, A=(80,100), B=(90,140) and C=(100,120), A is the baseline choice. Losing A permits B; C fails equality despite its cheaper total. Historical FD remains 100 even though the selected supplied total is 140. A separate authored case explicitly supplies a different completed history; the worksheet does not reset FD automatically. Its different completed history supplies FD 120 and chooses C with total 120. If a newly lower total is learned in real DUAL, FD can decrease; this frozen comparison does not advance that history.

Failing the sufficient feasibility condition does not prove a path loops. If advertisements remain but no locally feasible candidate exists, the worksheet reports that coordinated computation is needed and stops. No advertisements is a different state. Tied feasible choices do not certify installed multipath. Exact-prefix/table RIB selection, forwarding and endpoint return are independent declarations. Their combined result is conditional worksheet information, not an observed service transaction.

Inputs enforce fixed peer order, exactly three paths, strict booleans and safe whole metric integers from 1 to 1,000,000,000; supplied total must be at least RD within this monotonic-distance exercise. Scenarios, catalogs and results are fresh copies. Dynamic output uses text nodes. Native/semantic invalid input and unknown cases hide stale results; reset stays usable. It performs no router mutation. The actual lab has only one transit path and does not corroborate alternate/feasible-successor switchover, metric formulas, variance, active/query/SIA behavior or the full DUAL FSM.
