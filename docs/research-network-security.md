# Network Security source applicability — 2026-10-09

The primary assistant opened the cited NIST, RFC and vendor pages during this task. Source metadata in the authored records retains the exact URLs and check date. A check date is an access/applicability review, not proof that a vendor procedure was executed. The authoring file maps each topic to its applicable sources; the acceptance matrix separately records execution limits.

- NIST SP 800-30 Rev. 1 and the NIST CIA risk glossary support risk framing and separate consequences. Classroom worksheets do not calculate organizational likelihood or certify risk acceptance.
- Cisco IOS XE 17 IP Access List Overview supports ordered packet-filter evaluation and wildcard bits. Its absent/empty named-list caveat is retained. Some editing statements in this broad guide describe historical behavior; the course does not generalize them to every numbered or sequence-capable current implementation.
- Catalyst 9300 IOS XE 17.13 security guide provides a fixed release reference for snooping, secure-port and access authentication concepts. The newer consolidated first-hop guides separately support DAI/static-ARP precedence and IP Source Guard binding modes. Their platform support tables are not extrapolated to every Catalyst or release.
- Catalyst 9300 IOS XE 17.3 Private VLANs supplies role/mapping context. The model handles distinct supplied endpoint roles only; routed access, trunks and feature combinations require separate target verification.
- RFC 3748 supplies EAP architecture; RFC 2865 supplies classic RADIUS result context. This is not an endorsement of legacy transport security, a complete EAP method implementation or evidence of authenticated device traffic.
- IOS XE 17 management-plane guidance and Catalyst 9600 IOS XE 17.17 CoPP supply distinct platform context. Router MQC examples and system CPU queues are not interchangeable templates. The arithmetic excludes burst state, token replenishment, hardware accounting and actual CPU/drop outcomes.
- RFC 4301 supports IPsec architecture, RFC 7296 supports IKEv2 and the IOS XE VTI guide supports route-based attachment/observation context. Negotiated transforms, identities, lifetimes and product support require the actual deployment policy. The course does not select an unverified universal production cipher suite.
- NIST SP 800-41 Rev. 1 (2009) and SP 800-94 (2007) are architectural background for firewall/IDPS distinctions, not current product compatibility or threat-coverage certification. Their publication age is explicit.
- IOS XE 17 Zone-Based Policy Firewall supports directional zone pairs and inspect/pass/drop distinctions. The course retains self-zone and same-zone caveats instead of turning an inter-zone example into a universal default policy claim.
- ASA 9.20 firewall services describes ASA software behavior; Cisco Secure Firewall threat-protection guidance describes threat-defense policy/visibility concepts. ASA software, FTD and management tooling are distinct products/roles; model results never certify their deployment, licence or lifecycle status.
- Cloudflare's WAF documentation supplies a primary implementation example for HTTP rule/visibility concepts. The classroom detector consumes declared signals and does not implement that product or a payload scanner.
- NIST SP 800-207 supplies zero-trust architecture roles and resource-centric policy context; ISE 3.4 segmentation/policy documentation supplies policy-set and authorization context. A trusted network location, endpoint profile or server Accept alone does not prove protected identity, consumed access policy or application success.
- RFC 8446 supplies TLS 1.3 background for protected sessions. The optional actual loopback application fixture is deliberately separate from TLS/VPN/device deployment claims.
